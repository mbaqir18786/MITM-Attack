What is MITM?

A Man-in-the-Middle (MITM) attack occurs when an attacker sits between two communicating parties to intercept, and sometimes alter, the data being exchanged without their knowledge.

ARP Spoofing

Address Resolution Protocol (ARP) spoofing is a technique where an attacker sends fake ARP messages onto a LAN to link their MAC address with the IP address of a legitimate server/gateway.

Packet Interception

This is the process of capturing data packets as they travel across a network. Without encryption, these packets can be read like an open book.

HTTP vs HTTPS

HTTP sends data in plaintext (Insecure). HTTPS uses TLS/SSL to encrypt the data, ensuring that even if intercepted, it cannot be read by an attacker.
